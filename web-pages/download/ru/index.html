Почему скачивается файл APK?

Parlami сейчас — это первый независимый релиз. Размещение в Google Play требует дополнительных расходов и времени. Будучи студентом, я решил предоставить эту первую версию бесплатно и напрямую, пока идёт подготовка к публикации в магазинах приложений.

Файл публикуется напрямую из официального репозитория Parlami на GitHub. Приложение не требует аккаунта, а данные хранятся только на вашем устройстве.

  • Аккаунт не требуется
  • Без рекламы
  • Без трекеров аналитики
  • Без серверов Parlami
  • Учебные данные хранятся локально
  • Код и релизы открыты на GitHub

📱 Как установить Parlami на Android

Файл для загрузки — это стандартный установочный пакет APK для системы Android.

Поскольку приложение ещё не представлено в Google Play, Android может показать стандартное предупреждение об установке из внешнего источника. Это нормальная процедура для прямых установок.

Чтобы быть уверенным в подлинности версии, скачивайте её только по кнопке на этом сайте или на официальной странице релизов GitHub.
