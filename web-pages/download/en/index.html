Why download an APK?

Parlami is currently an independent initial release. Publishing on Google Play involves additional fees and procedures. As a student, I chose to make this first version available directly and for free while preparing for official store release.

The file is published directly from the official Parlami GitHub repository. The app requires no user account, and all your learning data stays strictly on your device.

  • No account required
  • No ads
  • No analytics trackers
  • No Parlami servers
  • Learning data stored locally
  • Open code and releases on GitHub

📱 Installing Parlami on Android

The download offered here is an APK file, the standard installation package format for Android applications.

Since Parlami is not yet distributed through Google Play, Android may display a security prompt about installing from external sources. This is standard behavior for direct installations.

To ensure you are downloading the genuine version, only use the button on this site or check the official GitHub releases page.

To learn exactly how Parlami handles data and which external services it interacts with, please read our Privacy Policy.
