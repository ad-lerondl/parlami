Pourquoi télécharger un APK ?

Parlami est actuellement une première version indépendante. La publication sur Google Play demande notamment des frais et des démarches supplémentaires. En tant qu'étudiant, j'ai choisi de rendre cette première version disponible directement, gratuitement, en attendant sa publication sur les stores.

Le fichier est publié depuis le dépôt GitHub officiel de Parlami. L'application ne nécessite pas de compte et les données d'apprentissage restent sur ton appareil.

  • Aucun compte nécessaire
  • Pas de publicité
  • Pas d'analytics
  • Pas de serveur Parlami
  • Données pédagogiques stockées localement
  • Code et versions publiés sur GitHub

📱 Installer Parlami sur Android

Le téléchargement proposé ici est un fichier APK, le format d'installation standard des applications Android.

Comme Parlami n'est pas encore distribué par Google Play, Android peut afficher un avertissement concernant l'installation depuis une source externe. C'est normal pour une application installée directement.

Pour vérifier que tu télécharges bien la bonne version, utilise uniquement le bouton présent sur ce site ou la page officielle des releases GitHub.

Pour connaître précisément les données utilisées par Parlami et les services externes auxquels l'application peut se connecter, consulte la politique de confidentialité.
