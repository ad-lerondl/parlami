Privacy Policy — Parlami

Last updated: August 28, 2026

1. Application Publisher

The Parlami application is published by:

Adam Lérondel
France
E-mail : ad-lerondl.apps@gmx.fr

Parlami is an Italian learning application primarily intended for vocabulary, conjugation, comprehension, and expression training.

2. General Principles

Parlami was designed to minimize personal data collection as much as possible.

  • no user account is required;
  • no registration is required;
  • no Parlami application server stores user progression;
  • no advertising is used;
  • no behavioral or advertising analytics tools are used;
  • no microphone, camera, contact, or location service is used;
  • exercise answers are not transmitted to a Parlami server;
  • progression data is not synchronized with a Parlami server.

3. Locally Stored Data

To enable the application to function and track progression, Parlami may locally save various educational data, including:

  • conjugation preferences;
  • display and training preferences;
  • words added to personal vocabulary;
  • translations and associated categories;
  • exercise results;
  • number of attempts and correct or incorrect answers;
  • consultation statistics;
  • review and consultation dates;
  • information necessary for the progression system to function.

This data is primarily stored locally on the device. On the Web version, some data may be kept in the browser's local storage, particularly IndexedDB.

Parlami currently does not synchronize this data with a remote server.

4. Exercise Answers

The user may enter text in certain exercises, particularly for conjugation, numbers, dates, times, vocabulary, or written expression.

These answers are used locally by the application to execute the exercises and calculate progression.

In the current version of Parlami, these answers are not sent to a server operated by the publisher and are not transmitted to an artificial intelligence service.

5. Vocabulary Import and Export

Parlami allows the user to import and export certain vocabulary data in JSON format.

An export may notably contain personal vocabulary, translations, categories, learning statistics, and associated progression information.

On Android, the file can be passed to the system's sharing menu. On the Web, the file can be generated and downloaded by the browser.

Once a file is shared with an application or service chosen by the user, its processing is the responsibility of that recipient and subject to their own privacy policy.

6. Radio Streams

Parlami offers an oral comprehension feature allowing users to listen to certain radio streams available on the Internet.

The current version specifically uses streams associated with RAI 1, RAI 2, RAI 3, RDS, Radio 105, and RTL 102.5.

When a user listens to a radio, their device establishes a connection with the stream provider. This provider may process certain technical information related to the connection, such as the IP address, date and time of connection, or technical information regarding the client used.

Parlami does not collect or transmit any audio recording from the user's microphone.

7. Links to External Sites

Certain features allow access to external resources, notably ANSA, La Repubblica, Corriere della Sera, Il Post, RAI News, and News in Slow Italian.

These resources are opened in the browser or in an external application. The services involved may apply their own privacy policies, cookies, trackers, and logging mechanisms.

8. Donations via Stripe

Parlami is a free application and no paid features are currently offered.

The application may offer a voluntary donation option to support its development. Payments are not processed directly by Parlami: the user is redirected to a payment page provided by Stripe.

Parlami does not receive or store the full credit card information entered on this page.

9. Web Version and Hosting

The Web version of Parlami may be hosted by Netlify. The host may process certain technical information necessary for the operation and security of the site, such as the IP address, date and time of requests, browser, system used, and technical log information.

10. Android Permissions

The Android version of Parlami uses permissions necessary for its network and audio features, notably Internet access and the Android mechanisms required for background audio playback.

Parlami currently does not request access to the microphone, camera, contacts, or location.

11. Absence of User Account

Parlami currently requires no user account. Therefore, there is no Parlami account to delete.

Local data can be deleted by clearing the application's data or uninstalling it, depending on the platform. On the Web, local data can be deleted from the browser's data management settings.

12. Data Retention

Educational data stored locally is kept as long as necessary for the application to function and until deleted by the user or the system used.

Data potentially processed by third-party services is retained according to the specific rules and policies of those services.
