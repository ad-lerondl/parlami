Parlami es una aplicación de aprendizaje de italiano destinada principalmente al entrenamiento de vocabulario, conjugación, comprensión y expresión.

2. Principios generales

Parlami ha sido diseñada para minimizar al máximo la recopilación de datos personales.

  • no se requiere cuenta de usuario;
  • no se requiere registro;
  • ningún servidor de Parlami almacena el progreso de los usuarios;
  • no se utiliza publicidad;
  • no se utilizan herramientas de análisis de comportamiento o publicidad;
  • no se utilizan micrófono, cámara, contactos ni servicios de ubicación;
  • las respuestas a los ejercicios no se transmiten a un servidor de Parlami;
  • los datos de progreso no se sincronizan con un servidor de Parlami.

3. Datos almacenados localmente

Para permitir el funcionamiento de la aplicación y el seguimiento del progreso, Parlami puede guardar localmente varios datos pedagógicos, incluyendo:

  • preferencias de conjugación;
  • preferencias de visualización y entrenamiento;
  • palabras añadidas al vocabulario personal;
  • traducciones y categorías asociadas;
  • resultados de ejercicios;
  • número de intentos y respuestas correctas o incorrectas;
  • estadísticas de consulta;
  • fechas de repaso y consulta;
  • información necesaria para el funcionamiento del progreso.

Estos datos se almacenan principalmente localmente en el dispositivo. En la versión web, algunos datos pueden guardarse en el almacenamiento local del navegador, en particular IndexedDB.

Actualmente, Parlami no sincroniza estos datos con un servidor remoto.

4. Respuestas a los ejercicios

El usuario puede introducir texto en ciertos ejercicios, particularmente para conjugación, números, fechas, horas, vocabulario o expresión escrita.

Estas respuestas son utilizadas localmente por la aplicación para realizar los ejercicios y calcular el progreso.

En la versión actual de Parlami, estas respuestas no se envían a un servidor operado por el editor y no se transmiten a un servicio de inteligencia artificial.

5. Importación y exportación de vocabulario

Parlami permite al usuario importar y exportar ciertos datos de vocabulario en formato JSON.

Una exportación puede contener específicamente el vocabulario personal, traducciones, categorías, estadísticas de aprendizaje e información de progreso asociada.

En Android, el archivo se puede pasar al menú de compartir del sistema. En la Web, el archivo puede ser generado y descargado por el navegador.

Una vez que un archivo se comparte con una aplicación o servicio elegido por el usuario, su procesamiento es responsabilidad de ese destinatario y está sujeto a su propia política de privacidad.

6. Flujos de radio

Parlami ofrece una función de comprensión oral que permite escuchar ciertos flujos de radio accesibles en Internet.

La versión actual utiliza específicamente flujos asociados a RAI 1, RAI 2, RAI 3, RDS, Radio 105 y RTL 102.5.

Cuando un usuario escucha una radio, su dispositivo establece una conexión con el proveedor del flujo. Este proveedor puede procesar cierta información técnica relacionada con la conexión, como la dirección IP, fecha y hora de conexión, o información técnica sobre el cliente utilizado.

Parlami no recopila ni transmite ninguna grabación de audio procedente del micrófono del usuario.

7. Enlaces a sitios externos

Ciertas funciones permiten el acceso a recursos externos, en particular ANSA, La Repubblica, Corriere della Sera, Il Post, RAI News y News in Slow Italian.

Estos recursos se abren en el navegador o en una aplicación externa. Los servicios involucrados pueden aplicar sus propias políticas de privacidad, cookies, rastreadores y mecanismos de registro.

8. Donaciones vía Stripe

Parlami es una aplicación gratuita y actualmente no se ofrecen funciones de pago.

La aplicación puede ofrecer una opción de donación voluntaria para apoyar su desarrollo. Los pagos no son procesados directamente por Parlami: el usuario es redirigido a una página de pago proporcionada por Stripe.

Parlami no recibe ni almacena la información completa de la tarjeta bancaria introducida en esta página.

9. Versión Web y alojamiento

La versión web de Parlami puede estar alojada por Netlify. El servidor puede procesar cierta información técnica necesaria para el funcionamiento y la seguridad del sitio, como la dirección IP, fecha y hora de las solicitudes, navegador, sistema utilizado e información relativa a los registros técnicos.

10. Permisos de Android

La versión para Android de Parlami utiliza permisos necesarios para sus funciones de red y audio, en particular acceso a Internet y los mecanismos de Android necesarios para la reproducción de audio en segundo plano.

Parlami actualmente no solicita acceso al micrófono, cámara, contactos o ubicación.

11. Ausencia de cuenta de usuario

Actualmente, Parlami no requiere una cuenta de usuario. Por lo tanto, no existe una cuenta de Parlami que eliminar.

Los datos locales se pueden eliminar borrando los datos de la aplicación o desinstalándola, según la plataforma. En la Web, los datos locales se pueden eliminar desde los ajustes de gestión de datos del navegador.

12. Retención de datos

Los datos pedagógicos almacenados localmente se conservan el tiempo que sea necesario para el funcionamiento de la aplicación y hasta su eliminación por el usuario o el sistema utilizado.

Los datos posiblemente procesados por servicios de terceros se conservan según las reglas y políticas específicas de esos servicios.

13. Derechos de los usuarios

Cuando se aplica el RGPD, los usuarios tienen, según las condiciones previstas por la normativa, derechos sobre sus datos personales, incluyendo los derechos de acceso, rectificación, supresión, limitación, oposición y, cuando se cumplen las condiciones, portabilidad.

Para cualquier pregunta relacionada con los datos personales procesados por el editor de Parlami:
