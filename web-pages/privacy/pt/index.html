Parlami é um aplicativo de aprendizado de italiano destinado principalmente ao treinamento de vocabulário, conjugação, compreensão e expressão.

2. Princípios Gerais

Parlami foi projetado para minimizar ao máximo a coleta de dados pessoais.

  • nenhuma conta de usuário é necessária;
  • nenhum registro é necessário;
  • nenhum servidor Parlami armazena o progresso dos usuários;
  • nenhuma publicidade é usada;
  • nenhuma ferramenta de análise comportamental ou publicidade é usada;
  • nenhum microfone, câmera, contatos ou serviço de localização é usado;
  • as respostas aos exercícios não são transmitidas a um servidor Parlami;
  • os dados de progresso não são sincronizados com um servidor Parlami.

3. Dados Armazenados Localmente

Para permitir o funcionamento do aplicativo e o acompanhamento do progresso, Parlami pode salvar localmente vários dados pedagógicos, incluindo:

  • preferências de conjugação;
  • preferências de exibição e treinamento;
  • palavras adicionadas ao vocabulário pessoal;
  • traduções e categorias associadas;
  • resultados de exercícios;
  • número de tentativas e respostas corretas ou incorretas;
  • estatísticas de consulta;
  • datas de revisão e consulta;
  • informações necessárias para o funcionamento do progresso.

Estes dados são armazenados principalmente localmente no dispositivo. Na versão web, alguns dados podem ser guardados no armazenamento local do navegador, em particular no IndexedDB.

Atualmente, Parlami não sincroniza esses dados com um servidor remoto.

4. Respostas aos Exercícios

O usuário pode inserir texto em certos exercícios, particularmente para conjugação, números, datas, horas, vocabulário ou expressão escrita.

Estas respostas são utilizadas localmente pelo aplicativo para executar os exercícios e calcular o progresso.

Na versão atual do Parlami, essas respostas não são enviadas a um servidor operado pelo editor e não são transmitidas a um serviço de inteligência artificial.

5. Importação e Exportação de Vocabulário

Parlami permite ao usuário importar e exportar certos dados de vocabulário no formato JSON.

Uma exportação pode conter especificamente o vocabulário pessoal, traduções, categorias, estatísticas de aprendizagem e informações de progresso associadas.

No Android, o arquivo pode ser passado ao menu de compartilhamento do sistema. Na Web, o arquivo pode ser gerado e baixado pelo navegador.

Uma vez que um arquivo é compartilhado com um aplicativo ou serviço escolhido pelo usuário, seu processamento é de responsabilidade desse destinatário e está sujeito à sua própria política de privacidade.

6. Fluxos de Rádio

Parlami oferece um recurso de compreensão oral que permite ouvir certos fluxos de rádio acessíveis na Internet.

A versão atual usa especificamente fluxos associados à RAI 1, RAI 2, RAI 3, RDS, Radio 105 e RTL 102.5.

Quando um usuário ouve uma rádio, seu dispositivo estabelece uma conexão com o provedor de fluxo. Este provedor pode processar certas informações técnicas relacionadas à conexão, como endereço IP, data e hora da conexão, ou informações técnicas sobre o cliente utilizado.

Parlami não coleta ou transmite qualquer gravação de áudio do microfone do usuário.

7. Links para Sites Externos

Certos recursos permitem acesso a recursos externos, nomeadamente ANSA, La Repubblica, Corriere della Sera, Il Post, RAI News e News in Slow Italian.

Estes recursos são abertos no navegador ou em um aplicativo externo. Os serviços envolvidos podem aplicar suas próprias políticas de privacidade, cookies, rastreadores e mecanismos de log.

8. Doações via Stripe

Parlami é um aplicativo gratuito e atualmente não oferece recursos pagos.

O aplicativo pode oferecer uma opção de doação voluntária para apoiar seu desenvolvimento. Os pagamentos não são processados diretamente por Parlami: o usuário é redirecionado a uma página de pagamento fornecida pela Stripe.

Parlami não recebe ou armazena as informações completas do cartão de crédito inseridas nesta página.

9. Versão Web e Hospedagem

A versão web do Parlami pode ser hospedada pelo Netlify. O servidor pode processar certas informações técnicas necessárias para a operação e segurança do site, como endereço IP, data e hora de solicitações, navegador, sistema utilizado e informações de registro técnico.

10. Permissões do Android

A versão Android do Parlami utiliza permissões necessárias para seus recursos de rede e áudio, especificamente o acesso à Internet e os mecanismos Android necessários para reprodução de áudio em segundo plano.

Parlami atualmente não solicita acesso ao microfone, câmera, contatos ou localização.

11. Ausência de Conta de Usuário

Atualmente, Parlami não exige uma conta de usuário. Portanto, não há conta Parlami a ser excluída.

Os dados locais podem ser excluídos limpando os dados do aplicativo ou desinstalando-o, dependendo da plataforma. Na Web, os dados locais podem ser excluídos nas configurações de gerenciamento de dados do navegador.

12. Retenção de Dados

Os dados pedagógicos armazenados localmente são mantidos pelo tempo necessário para o funcionamento do aplicativo e até serem excluídos pelo usuário ou pelo sistema utilizado.

Dados possivelmente processados por serviços de terceiros são mantidos de acordo com as regras e políticas específicas desses serviços.

13. Direitos dos Usuários

Quando o RGPD se aplica, os usuários têm direitos específicos sobre seus dados pessoais nas condições previstas pela regulamentação, nomeadamente os direitos de acesso, retificação, apagamento, limitação, oposição e, quando as condições são cumpridas, portabilidade.

Esta política pode ser atualizada à medida que os recursos, serviços utilizados ou práticas de processamento de dados do Parlami evoluírem.
